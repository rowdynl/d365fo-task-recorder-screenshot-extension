# AGENTS.md

## Project

D365FO Task Recorder Screenshot extension for Microsoft Edge.

## AI-assisted development

This repository may be developed and maintained with the assistance of AI coding agents.

AI-generated changes must:

- Be reviewed before merging
- Maintain Microsoft Edge Manifest V3 compatibility
- Preserve D365FO Task Recorder functionality
- Avoid introducing unnecessary permissions
- Never include secrets or credentials

## Testing

Before committing changes:

- Load the extension unpacked in Microsoft Edge
- Test screenshot capture in D365FO Task Recorder
- Verify the task recorder pane is correctly removed from screenshots
