# Privacy Policy

## D365FO Task Recorder Screenshot

D365FO Task Recorder Screenshot is a browser extension that captures
screenshots while using the Task Recorder in Microsoft Dynamics 365
Finance and Operations.

### Data collection

The extension does not collect, store, transmit, sell, or share personal
data with the extension developer or third parties.

Screenshots are processed locally in the user's browser and are returned
to the Dynamics 365 Finance and Operations Task Recorder for inclusion
in Task Recorder documentation.

The extension does not transmit screenshots to the developer or to an
external service.

### Browser permissions

The extension requires permission to capture the currently visible
browser tab. This permission is used solely to take screenshots when
requested by Dynamics 365 Finance and Operations Task Recorder.

Although the browser screenshot API requires broad host permission for
automatic screenshot capture, the extension only processes screenshot
requests originating from supported Dynamics 365 Finance and Operations
pages.

The extension does not use this permission to monitor browsing activity.

### Remote services

The extension does not use analytics, tracking, advertising, or remotely
hosted executable code.

### Data retention

The extension does not retain captured screenshots or other user data.

### Changes

Any changes to this privacy policy will be published in this repository.

### Contact

For questions about this privacy policy, please open an issue in this
GitHub repository.
